## 九键简拼补词与尾音补全

`bim_t9` 主通道仅使用完整音节生成词句，并启用末尾音节补全，避免末尾只输入一个码时，
整串数字退化为逐码简拼造句。九键一个数字对应多个字母，补全不保证猜中尚未输入的尾音。

通过 `lua/t9_mixed_translator.lua` 调用独立的 `bim_t9_mixed` fuzz 棱镜补充简拼词条。
主通道首选先输出；补充通道只接受覆盖整个输入段的系统词条，不输出自动造句或只消费部分输入的词条。
补词最多补充8项、扫描64项，扫描限制不是底层查询时间上限。
显式分词和拼音筛选后的字母输入只走主通道；任意多字简拼不再自动拼成长句。

补充通道禁用用户词库，用户学习统一由主通道处理，避免重复累计词频。
更新时需同时部署两个 schema、两个 prism 和 Lua 文件；`bim_t9_mixed` 仅作为依赖，
不要单独加入方案列表。若补词 schema/prism 缺失或加载失败，则退回主通道。

`5468` 可通过补词通道恢复“今天”；完整输入 `962496542` 可匹配“我爱我家”。
`96249654` 仍可按 `wo+ai+wo+ji` 造句，不能把只覆盖7码的“我爱我家”当作整段匹配。
