## 九键简拼补词

`bim_t9` 的主通道保留 `abbrev`，通过 `lua/t9_mixed_translator.lua` 调用独立的
`bim_t9_mixed` fuzz 棱镜补词。主通道首选保持不变；补充通道只接受覆盖整个输入段的系统词条，
不输出自动造句或只消费部分输入的词条。补词最多补充8项、扫描64项，显式分词和拼音筛选后的字母输入只走主通道。

补充通道禁用用户词库，用户学习统一由主通道处理，避免重复累计词频。
更新时需同时部署两个 schema、两个 prism 和 Lua 文件；`bim_t9_mixed` 仅作为依赖，
不要单独加入方案列表。若补词 schema/prism 缺失或加载失败，则退回主通道并保留原有候选。

此功能恢复的是简拼词条候选，不保证未完成尾音自动补全。例如 `96249654` 仍按原通道的
`wo+ai+wo+ji` 造句；完整输入 `962496542` 才匹配完整的“我爱我家”。
